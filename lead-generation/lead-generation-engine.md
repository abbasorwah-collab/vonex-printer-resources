# Vonex Lead Generation Engine

## Goal

Turn the SEO system into a measurable lead-generation system for vonex.ca and shop.vonex.ca.

## Property roles

### vonex.ca
Primary lead-generation property for:
- printer repair
- copier service
- printer/copier leasing
- managed print services
- office equipment
- maintenance contracts
- Saskatchewan business customers

### shop.vonex.ca
Primary ecommerce property for:
- toner
- ink
- printers
- label printers
- office supplies
- printer supplies

Shop can also identify business buyers and repeat-purchase opportunities, but should not be presented as a local physical business.

## Lead funnel

Search
→ landing page
→ CTA
→ phone/form
→ lead
→ qualification
→ quote
→ sale/service agreement
→ revenue

## Lead sources to track

- organic search
- Google Business Profile
- referral/backlink
- direct
- paid search if used
- email
- phone
- contact form
- ecommerce organic purchase

## High-intent CTA opportunities

For vonex.ca:
- Request a quote
- Book a printer/copier assessment
- Request service
- Get lease/rental pricing
- Request managed print assessment
- Ask about toner/service

For shop.vonex.ca:
- Add to cart
- Buy now
- Create account
- Request bulk pricing
- Request business pricing
- Ask about compatibility

## Lead qualification fields

Where appropriate:
- company
- contact
- city
- province
- equipment type
- brand
- model
- number of devices
- estimated monthly print volume
- service/repair need
- lease/rental need
- toner/supply need
- urgency
- source page
- keyword/query when available
- estimated opportunity value
- status

Do not collect unnecessary personal information.

## Lead stages

new
→ contacted
→ qualified
→ quote
→ won
→ lost
→ nurture

## Lead-generation SEO priorities

1. Improve existing high-intent service pages.
2. Improve CTAs on pages already receiving organic traffic.
3. Build industry landing pages with genuinely useful content.
4. Build city/service pages only where Vonex genuinely serves the market.
5. Connect brand/model searches to service and quote pages.
6. Use calculators/tools as lead-generation assets where appropriate.
7. Recover abandoned or unconverted high-intent traffic where systems permit.
8. Measure revenue, not just rankings.

## Daily lead-generation review

After SEO opportunity review, ask:
- Which page received qualified traffic?
- Which page has strong impressions but weak CTA performance?
- Which search intent indicates a service/quote need?
- Which page should receive a stronger CTA?
- Which industry/city/brand/model has evidence of demand?
- Which leads need follow-up?
- Which SEO pages generated actual business value?

## Guardrails

Do not:
- fake leads
- create fake reviews
- create fake inquiries
- use deceptive forms
- hide CTAs
- create misleading local claims
- buy low-quality leads solely to inflate metrics

## Core KPI

Track:
- organic leads
- qualified leads
- quotes
- closed sales
- service jobs
- revenue
- lead-to-quote rate
- quote-to-sale rate
- revenue by landing page
- revenue by query/category when attribution is available
