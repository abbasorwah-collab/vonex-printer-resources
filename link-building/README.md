# Vonex Link Building System

This folder tracks legitimate authority-building opportunities for Vonex.

## Rules

- Prefer relevant Canadian, Saskatchewan, office-equipment, printer, business, technology and professional resources.
- Never create duplicate business listings.
- Never use automated spam submissions, comment spam, fake profiles, paid link schemes, or mass directory blasts.
- Keep NAP information consistent where a physical business listing is appropriate.
- Use natural anchor text and link to the most relevant page, not always the homepage.
- Review each opportunity before submitting or contacting the site.
- Record the result in `external-opportunity-tracker.csv`.

## Status values

- `not-started`
- `researching`
- `ready`
- `submitted`
- `approved`
- `live`
- `rejected`
- `not-relevant`

## Target-page strategy

External links should be distributed across useful pages such as:

- printer repair
- copier service
- managed print
- printer leasing
- office equipment
- printer maintenance
- brand/service guides
- useful educational articles

Do not force an exact-match keyword anchor. Brand, URL, descriptive and partial-match anchors are preferable.

## Shop.vonex.ca

The shop is a separate Canada-wide ecommerce property. Build its backlink list separately rather than mixing ecommerce links with local Saskatoon citations.

Focus shop opportunities on:

- toner and ink resources
- printer-supply resources
- Canadian ecommerce/business directories
- office-supply resources
- printer buying guides
- manufacturer/resource pages where appropriate
- useful business technology resources

The shop should not be represented as a separate physical location.
