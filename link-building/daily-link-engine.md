# Daily Link Engine

Goal: generate 1–3 legitimate backlink opportunities per day for Vonex, while keeping prospects separate from verified live backlinks.

## Daily rotation

1. Commercial copier lease / copier rental
2. Printer lease / printer rental
3. Printer and copier repair
4. Managed print services
5. Saskatoon/local service pages
6. Brand/service pages
7. Shop collection pages
8. Shop individual product pages
9. Educational resources and guides

## Required fields

- Date researched
- Source website
- Source URL
- Source type
- Why the source is relevant
- Vonex target URL
- Suggested natural anchor
- Outreach/contact method
- Status
- Date submitted
- Live link URL
- Date verified

## Status values

prospect → researched → outreach-ready → contacted → approved → live → verified → rejected → not-relevant

## Rules

- Never treat a prospect as a backlink.
- Never create fake listings or fake profiles.
- Never mass-submit directory listings.
- Never use comment/forum spam.
- Never buy links solely for ranking manipulation.
- Prefer relevant Canadian, Saskatchewan, business, office-equipment, technology and ecommerce resources.
- Rotate target pages so the homepage is not the only destination.
- Use natural brand, descriptive and partial-match anchors.
- Verify every claimed live link before counting it.

## Daily objective

Find 1–3 strong opportunities rather than a large volume of weak links. Over time, build a verified backlink portfolio across local service pages, commercial copier leasing/rental pages, educational resources, shop collections and individual products.
