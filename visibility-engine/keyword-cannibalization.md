# Keyword Cannibalization Detector

## Goal
Identify multiple Vonex pages competing for the same search intent.

## Check
For each important query:
- which Vonex URLs receive impressions
- which URL has the strongest position
- whether multiple product/collection/guide pages target the same intent
- whether the ranking page satisfies the search intent
- whether internal links consistently point to the preferred page

## Resolution options
- choose one primary page
- consolidate genuinely duplicate content
- differentiate search intent
- strengthen internal links to the preferred page
- adjust titles/H1s where necessary
- redirect only when pages are genuinely redundant and a redirect is appropriate

## Product example
Primary:
Brother TN920 toner product/collection page

Supporting:
Brother toner buying guide
Brother HL-L8360CDW guide

The guide should support the commercial product page rather than competing with it.

## Rules
Do not merge pages solely because they share a keyword. Preserve useful distinct search intent.
