# Image SEO Implementation Checklist

## Before publishing
- Confirm the image is relevant to the page.
- Prefer an original Vonex photo when available.
- Rename the file descriptively before upload.
- Write concise, accurate alt text.
- Add a caption only when it adds useful context.
- Preserve genuine EXIF/GPS metadata if already present.
- Do not fabricate location data.
- Compress/resize for performance.
- Confirm the image is visible to users and not hidden solely for SEO.

## Local pages
Use real Saskatoon/Saskatchewan context where it is actually represented by the photo.

## Shop
Use product photography, packaging, compatibility, and fulfillment images. Do not add fake location metadata to make national ecommerce pages appear local.

## Measurement
Track:
- image indexability
- page speed/image weight
- image search impressions/clicks where available
- organic conversions/calls from pages using original assets
