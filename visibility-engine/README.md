# Vonex Visibility Engine

This module connects local SEO, ecommerce SEO, image assets, reviews, industry pages, lead capture, and offsite authority.

## Modules
- Industry landing pages
- Keyword-to-lead mapping
- Review engine
- Entity consistency
- Image SEO and geo-relevant asset management
- Calculator/tool roadmap
- Lead/call capture

## Image SEO rules
1. Prefer original Vonex photos over stock images.
2. Use descriptive filenames and natural alt text.
3. Keep genuine location context where it is relevant to the page.
4. Preserve legitimate EXIF/GPS metadata when it exists; do not fabricate coordinates or use GPS as a ranking trick.
5. Use images that support the page's actual topic and conversion goal.
6. For shop.vonex.ca, prioritize product/entity/compatibility information rather than artificial geographic signals.
7. Compress images and use modern formats where the storefront supports them.
8. Do not keyword-stuff filenames, alt text, captions, or metadata.

See `image-seo/image-asset-tracker.csv` for the working inventory.
