# GSC Product Optimizer

## Purpose
Turn Search Console query/page data into prioritized product-page SEO actions for shop.vonex.ca.

## Inputs
- product URL
- query
- impressions
- clicks
- CTR
- average position
- country/device where useful
- product/brand/model
- conversion data when available

## Priority opportunities
1. Relevant commercial queries with meaningful impressions and position 4–20.
2. High-impression queries with weak CTR.
3. Rising queries where the page is already relevant.
4. Queries where a product page ranks but another page would better satisfy intent.
5. Product pages with strong visibility but weak conversion.

## Actions
- improve title/H1
- improve product description
- strengthen compatibility information
- add relevant internal links
- connect product to brand/model/collection
- improve structured data
- improve image metadata
- create a useful supporting guide when the intent is informational

Never invent product facts or compatibility.

## Output
Record each opportunity in product-keyword-tracker.csv with the action, status and next review date.
