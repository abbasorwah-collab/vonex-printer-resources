# Machine Model SEO Engine

## Goal
Capture useful model-specific searches for printer/copier sales, service, repair, leasing and supplies while avoiding thin or duplicate pages.

## Architecture
Brand → family/series → model → relevant intent.

## Priority families
- Konica Minolta bizhub
- Toshiba e-STUDIO
- Canon imageRUNNER ADVANCE / imageRUNNER
- Kyocera TASKalfa / ECOSYS
- HP LaserJet Enterprise / Managed
- Lexmark MX / CX
- Xerox VersaLink / AltaLink
- Brother business laser
- Zebra ZD / ZT

## Page eligibility
Create a model page only when there is enough unique useful information and a genuine Vonex business purpose: service/repair, lease/rental, supplies, equipment information, or troubleshooting/maintenance.

## Page template
H1 → machine overview → verified specifications → service/maintenance → supplies → lease/replacement where relevant → related Vonex pages → useful FAQ → CTA.

## Internal-link model
Model → brand → repair/service → lease/rental → managed print → supplies.
Brand → model pages.
Guides → models only when genuinely relevant.
Shop products → models only when compatibility is verified.

## Quality rules
- Verify specifications against manufacturer documentation before publishing.
- Do not create pages solely from model names.
- Avoid near-duplicate model pages; use family pages/comparison tables when content is substantially the same.
- Prefer original Vonex equipment/service photos or properly licensed product imagery.
- Never fabricate GPS/EXIF metadata.
- Use accurate authorization/dealer language only where verified.
- Track calls, service requests, quotes, ecommerce conversions and indexation.
