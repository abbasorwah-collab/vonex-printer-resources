# Canon Printer & Copier Repair Guide

Start with the exact Canon model, error message and symptoms. Common problems include paper jams, streaks, faded output, cartridge warnings, scanner issues, network problems and repeated error codes.

## Basic checks
- Record the exact error message.
- Check paper and consumable warnings.
- Test whether the issue affects every user.
- Restart normally when the manufacturer documentation permits it.

If the problem continues, arrange qualified service. See [Vonex printer and copier repairs](https://vonex.ca/repairs).

If the device is leased, check the service agreement before arranging outside work.
