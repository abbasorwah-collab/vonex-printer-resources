# Toshiba Printer & Copier Repair Guide

Start with the exact Toshiba model, error message and symptoms. Common issues include paper jams, print-quality problems, consumable warnings, scanner issues and network or print-queue problems.

## Basic checks
- Record the error message.
- Check paper and consumable warnings.
- Determine whether all users are affected.
- Restart normally when the manufacturer documentation permits it.

If the issue continues, arrange qualified service. See [Vonex printer and copier repairs](https://vonex.ca/repairs).

For leased equipment, review the service agreement before arranging outside service.
