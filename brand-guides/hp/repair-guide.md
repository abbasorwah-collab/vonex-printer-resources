# HP Printer Repair Guide

Start with the exact HP model, error message and symptoms. Common issues include paper jams, faded or streaked output, cartridge warnings, scanner problems and network or print-queue issues.

## Basic checks
- Record the error message.
- Check paper and consumable warnings.
- Test whether the issue affects every user.
- Restart normally when the manufacturer documentation permits it.

If the issue continues, arrange qualified service. See [Vonex HP printer service in Saskatoon](https://vonex.ca/hp-printer-service-saskatoon).

If the printer is leased, check the service agreement before arranging outside service.
