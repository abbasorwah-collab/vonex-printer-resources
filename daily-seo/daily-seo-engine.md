# Vonex Daily SEO Engine

Updated: 2026-09-29

## Goal

Run a daily SEO operating cycle for both properties without blindly repeating the same work.

- vonex.ca: local Saskatchewan office-equipment sales, leasing, managed print and onsite service.
- shop.vonex.ca: Canada-wide ecommerce for toner, ink, printers and office supplies.

The engine discovers opportunities, prioritizes them, prepares actions and records outcomes. It does not automatically publish website changes, create listings, create reviews or build artificial links.

## Daily cycle

### 1. Search performance
Review Google Search Console for:
- queries with meaningful impressions and low CTR
- queries/pages trending up or down
- pages ranking in useful opportunity ranges
- new non-branded queries
- unexpected queries
- Canada-wide shop opportunities
- Regina/Saskatchewan local opportunities

Google Search Console provides clicks, impressions, CTR and position and supports query/page/country/device analysis. Focus on trends and page/query opportunities rather than position alone.

### 2. Technical health
Check:
- 404s and broken internal links
- redirect chains
- canonical problems
- noindex issues
- sitemap changes
- orphan URLs
- indexing anomalies
- structured-data problems
- major performance regressions

### 3. Internal links
Use the existing internal-link audit to find:
- pages with weak incoming links
- relevant pages that should link to priority commercial pages
- brand → model → service/supplies relationships
- article → service → CTA relationships

### 4. Offsite authority
Find 1–3 legitimate opportunities:
- industry associations
- chambers
- manufacturers
- suppliers
- Canadian business resources
- local organizations
- editorial/resource pages
- unlinked mentions
- broken-link replacement opportunities

Never mass-submit.

### 5. Local SEO
Priority order:
1. Regina
2. Saskatoon
3. Prince Albert
4. Moose Jaw
5. Yorkton
6. North Battleford
7. Warman/Martensville
8. other genuine Saskatchewan service markets

Check citation consistency, legitimate local resources, service-area relevance and local content opportunities.

Never create fake locations.

### 6. Shop SEO
Rotate systematically:
- collections
- brand collections
- toner/ink categories
- printer supplies
- office supplies
- buying guides
- high-priority products

For products, inspect:
- search demand
- title quality
- description quality
- compatibility information
- internal links
- collection placement
- indexability
- useful external resource opportunities

Do not create thin product pages solely for SEO.

### 7. Product keyword SEO
Run `visibility-engine/product-keyword-engine.md` for the next product batch.

For each selected product:
- identify the primary keyword
- identify relevant secondary/model/compatibility terms
- classify search intent
- use Search Console data when available
- prioritize meaningful impressions and strong commercial relevance
- record the work in `visibility-engine/product-keyword-tracker.csv`

Do not invent compatibility, specifications or manufacturer relationships.

### 8. Content improvement
Prefer improving pages that already have impressions before creating new pages.

Possible actions:
- improve title/meta
- clarify H1
- expand useful answers
- add model/brand relationships
- add internal links
- add original images
- strengthen CTAs
- improve comparison tables
- add calculators/tools where genuinely useful

### 9. Conversion review
Connect SEO to:
Search → landing page → call/form → quote → sale.

Track useful business outcomes where data is available.

### 10. Record
Every completed action should record:
- date
- property
- URL
- opportunity
- action
- status
- evidence/result
- next step

## Rotation rules

Do not repeat the same task every day.

Use a rotating queue:
- Monday: Search Console + technical
- Tuesday: Regina/local authority
- Wednesday: shop collections/brands
- Thursday: product keywords/model pages
- Friday: backlinks/outreach
- Saturday: content/internal links
- Sunday: measurement/backlog cleanup

The daily task can be adjusted when a critical issue appears.

## Priority scoring

High:
- existing page with strong impressions
- important commercial query
- technical/indexing issue
- Regina priority page
- high-value product/collection
- legitimate authority opportunity

Medium:
- content enhancement
- internal-link opportunity
- secondary local market
- useful brand/model expansion

Low:
- speculative page creation
- weak backlink prospect
- low-demand product
- cosmetic change without measurable purpose

## Guardrails

Never:
- mass-submit directories
- buy links solely for ranking
- create fake reviews
- create fake locations
- create duplicate business profiles
- keyword-stuff anchors or reviews
- generate thin location pages
- create hundreds of near-duplicate model pages
- automatically publish risky SEO changes

## Success metrics

Primary:
- organic clicks
- qualified leads
- quote requests
- calls
- sales/revenue attributable to organic traffic

Secondary:
- impressions
- CTR
- indexed pages
- useful ranking movement
- quality backlinks
- local visibility
- product/collection visibility
- relevant product queries

## Daily completion standard

A day is successful if the system:
1. Finds the highest-value new opportunity available.
2. Completes or prepares a legitimate action.
3. Records the result.
4. Leaves a clear next action.
5. Does not create unnecessary SEO noise.
